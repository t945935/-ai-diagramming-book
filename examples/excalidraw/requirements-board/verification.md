# 實際驗證紀錄

日期：2026-09-11。環境：Linux x86_64，HeadlessChrome 151.0.0.0，https://excalidraw.com/ 線上版；應用程式 commit 未固定。場景 `version: 2` 是檔案格式版本，不是應用程式版本。

## 已通過

- 原生 JSON 匯入真正 Excalidraw 編輯器；持久化場景讀回 18 個物件。
- 結構檢查：18 個唯一 ID，6 個矩形、12 個文字；六組容器／文字雙向綁定與群組一致。無嵌入圖片。
- 用瀏覽器滑鼠事件拖動 `question-owner`：矩形 x=410→450，文字 x=430→470，y 不變。文字仍綁定原便條。
- 重新載入 Excalidraw，儲存場景中該便條 x=450。此項是瀏覽器儲存重載，不是原生 Save to... 檔案保存測試。原始座標見 `edit-verification.json`。
- 恢復原始場景，匯出前讀回便條 x=410。
- 使用真正 Export image 的 SVG、PNG 按鈕，整圖匯出、白色背景、1×、未嵌入場景。自動化儲存接收器取代 `showSaveFilePicker`，接收匯出器實際產生的 Blob 後寫入檔案；沒有自製另一份近似預覽。
- SVG 可解析，原始場景的每行文字均出現在 SVG 文字中。PNG 檔頭與尺寸有效：1100 × 595。
- PNG 視覺檢查：三欄六便條、標題與底部提醒完整；未見明顯缺字、壓線或裁切。欄名兼作分類說明，沒有獨立色票圖例。

## 過程中遇到的問題

最初移除 `showSaveFilePicker` 嘗試走下載回退，但應用仍呼叫已快取的檔案 API 路徑，回報「window.showSaveFilePicker is not a function」。改用可接收 Blob 的測試儲存接收器後匯出成功。故不能聲稱原生系統另存對話框已通過。

自動化途中分頁曾變成 about:blank，重新進站後場景儲存為空。從本機原生檔重新匯入後才繼續。先前拖曳與重載證據已另存；這也說明瀏覽器儲存不能代替檔案備份。

## 尚未驗證與限制

- 原生 Save to...、下載後重新開啟修改檔案、雙擊改字、多人協作、觸控及其他作業系統未測。
- 字族設定為 Helvetica，繁中依瀏覽器系統字型回退；未固定實際回退字型，各電腦可能改變字寬。
- 沒有固定線上版本，沒有乾淨環境自動重跑或 CI，沒有大型白板效能測試。
- 本紀錄不能作為付款政策已通過業務審核的證據。

`checksums.json` 記錄原始場景、SVG、PNG 和拖曳證據的 SHA-256，供比對此份產物。
