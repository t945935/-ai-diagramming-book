下載原生場景後拖入 https://excalidraw.com/。先保存既有工作；選中便條移動時檢查文字跟隨。主選單 Save to... 保存修改版本，再重開檢查。Export image 匯出時不要勾選 Only selected，除非你真的只要局部。

此次使用 Excalidraw 線上版及 Linux HeadlessChrome 151.0.0.0，未固定線上程式版本。原始場景 18 個物件，含 6 個矩形與 12 個文字；無外部圖片。原生保存對話框、多人協作與跨平台尚未測試。瀏覽器儲存不可當作唯一備份。
