# 正式隨書發布前檢查表

狀態：模板，尚未完成正式發布。核心 CI 的既有成功不能自動勾選其他項目。

- [ ] 作者確認公開範圍與授權方案；書稿、範例、字型及第三方資源分開查。
- [ ] 指定來源 commit 與預定 tag；main 不直接充當紙本版本。
- [ ] 逐項列出預定交付原始檔與衍生圖，不打包登入資料、node_modules 或私人筆記。
- [ ] 在選定 commit 執行核心測試，確認對應 SHA 的 GitHub run 結果。
- [ ] 在具備工具的環境執行完整現有測試，另記沒有涵蓋的渲染器。
- [ ] 逐圖核對需求、字型、標籤、裁切與實際閱讀尺寸。
- [ ] 可編輯檔真正修改、保存、重新開啟，確認端點／群組不斷。
- [ ] 在乾淨下載或解壓環境按照讀者說明重做，不借用維護者私有路徑。
- [ ] 檢查秘密、個資、內部網址、原生場景、註解及外部 include。
- [ ] 審查套件漏洞公告並記錄時間、範圍及尚未處理項。
- [ ] 產物指紋與來源版本匹配；確認指紋只代表內容識別，不是安全簽章。
- [ ] 發布前由作者批准 tag／Release／授權；不由 CI 自行猜測版本名稱。
- [ ] 發布後從遠端重新下載，驗證清單及指紋，再提供讀者連結。

待填：來源 commit／審閱者／授權決定／驗證環境／不通過項／發布批准依據。
