# Excalidraw 需求白板提示詞

請為虛構「線上訂單與客服平台」建立可編輯的 `.excalidraw` JSON 場景。

標題：付款結果未知：需求討論白板。
副標題必須註明「虛構教學案例｜欄位表示決策狀態，不是時間順序」。

三欄各兩張便條：
- 已確認：結果未知不等於失敗／保留待確認狀態；不自動重送扣款／先查原付款結果。
- 待釐清：對帳間隔與總期限？／需要規格決策；誰接手人工處理？／庫存保留多久？
- 暫不處理：退款與出貨流程／另圖討論；客服後台與通知／本次不展開。

不可自行補查詢次數、間隔、期限或人名；不可畫成循序流程。分類同時有欄名與顏色，不只靠顏色。底部提醒：未定事項不可讓 AI 自行補完；移動欄位前先記錄決策依據。

每張便條使用原生矩形與文字，設定相互文字綁定及群組。所有 ID 唯一。禁止用整張圖片冒充可編輯內容，不加入外部圖片或連結。

交付 JSON、需確認的限制與驗收清單。驗收必須包括：真實編輯器匯入、拖曳框和文字同行、保存後重開、完整 SVG／PNG 匯出、繁中與裁切檢查。未執行的項目一律標示未測，不得聲稱成功。
