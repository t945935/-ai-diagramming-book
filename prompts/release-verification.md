# AI 圖表交付檢查提示詞

請針對指定來源 commit 做交付檢查，不建立正式 Release，除非另外取得批准。

輸入：〔Repo、精確 commit、預定檔案清單、工具環境、需求與授權狀態〕。

依序確認：
1. 原始檔與衍生圖的權威關係、來源指紋及變更。
2. 可執行的核心與渲染測試；區分本機結果、遠端 CI 結果與人工檢查。
3. GitHub run 的 head SHA、job、結論；不能只憑綠色圖示推定所有測試通過。
4. 文字、裁切、端點、群組、真實保存與重開；缺環境就明示未測。
5. Secrets、個資、嵌入場景、外部資源及授權；不要打印完整環境變數或憑證。
6. 套件公告檢查的時間與涵蓋範圍；零公告不等於沒有風險。

交付實際命令、退出碼、來源版本、證據連結、未完成項。不可自動提權、加入部署金鑰、關閉安全限制、建立正式版本或猜測授權。遠端寫入後要讀回指定目標才能宣稱成功。
