# draw.io 架構圖提示詞

產生一份可在 diagrams.net 開啟的未壓縮 .drawio XML。

這是虛構線上訂單平台的同步呼叫視圖。使用五個可編輯節點：client（使用者瀏覽器）、web（Web 前端）、orders（訂單 API）、payment（外部支付服務）、db（訂單資料庫）。

建立四條帶箭頭的連線：client → web、web → orders、orders → payment、orders → db。箭頭表示呼叫方向，回應省略；不得從位置推導時序。外部支付服務要在文字中標為外部，顏色只作輔助。

使用內建矩形及資料庫形狀；文字與節點應可單獨編輯，不准把整圖做成圖片。每個 mxCell ID 唯一；連線必須用 source、target 綁定現有節點，不能只用固定座標假裝相連。

使用繁體中文、html=0、適當留白，不使用外部圖片、連結或可執行內容。圖下註明退款、回呼、庫存及客服不在本圖內。不要宣稱這是完整生產架構。

交付 XML 與驗證清單：XML 可解析、ID 唯一、連線端點存在、編輯器能載入、拖曳後線條跟隨、修改後能重新載入。沒有實際測試的項目必須標為未驗證。

## 局部修改

請以提供的現有檔案為基礎，只修改指定節點的標籤／座標，保留其他 ID、邊與人工排版。不自動重畫整張圖。
