# PlantUML 三圖提示詞

先提供 requirements.md，再分別生成付款時序、訂單狀態與概念類別圖，每檔一圖，使用 @startuml／@enduml。

固定英文 ID、繁體中文標籤及 Noto Sans CJK TC。狀態／類別圖使用 !pragma layout smetana；不用遠端 include 或外部圖像。

時序圖宣告前端、API、資料庫及支付服務。以同一 alt 的三分支表達成功、明確失敗與等待逾時未知。逾時是 API 觀察，不是假造支付服務的回覆。資料庫寫入成功等前提須標明。

狀態圖包含待付款、付款處理中、待確認、已付款、已關閉與人工處理。只重試查詢，未知結果查詢最多三次；n 是本次查詢完成或逾時後累計次數。不要把第三次已確認成功也導向人工。

類別圖描述訂單對付款請求 0..1、付款請求對自動查詢 0..3，包含查詢逾時紀錄。不擅自使用組合關係或聲稱已生成資料庫約束。

交付跨圖一致性清單與未定義問題。實際渲染後檢查中文、字線重疊與基數；未執行不得宣稱測試通過。
