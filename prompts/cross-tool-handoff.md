# 跨工具交接提示詞

請依提供的需求與原始檔建立跨工具交接對照，不要求畫面相同。

輸入：〔來源工具／原始檔／版本／需求範圍〕
目標：〔目標工具／用途／是否需要人工拖曳〕
已確認規則：〔填寫〕
未定事項：〔填寫〕

先交付：
1. 概念、來源原生 ID、目標 ID、來源依據、對應理由與限制。
2. 每種箭頭的意義；不同語意不可混在同一個關係集合。
3. 可保留、需要重建、缺乏依據不能推定的資訊清單。
4. 原始檔／生成程式／預覽的權威順序。
5. 本次實際要修改與明確不修改的檔案。

不得只憑同名合併元件；付款模組不等於外部支付服務，動作不等於狀態。未提供的部署映射、責任人或數值保持未知。

如獲准實作，先定義共享契約再修改，輸出原生檔與預覽，測試端點、範圍、語意、視覺及真實編輯重開。未測的工具和轉換方式標示未測，禁止把圖片匯出說成無損往返。
