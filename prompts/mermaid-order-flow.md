# Mermaid 訂單流程提示詞

先提供 examples/mermaid/order-flow/requirements.md 的完整內容，再使用以下要求：

請根據提供的 R1–R8 畫 Mermaid flowchart TD。

使用唯一英文節點 ID、加雙引號的繁體中文標籤，箭頭表示處理流程。每個決策出口必須標示條件。付款成功、明確失敗與逾時未知必須分開；未知結果不得畫成付款失敗或直接釋放庫存。

不得增加規格以外的退款、自動重試或出貨。不在本圖處理的狀態應明確交接，不假裝流程已完整。

只使用基本節點與連線語法，不使用 HTML、click、外部圖片或初始化指令。提供 accTitle 與 accDescr。不要使用小寫 end 作為節點 ID。

交付原始碼、R1–R8 對照表與待確認事項。未實際渲染不得宣稱已通過驗證。

## 修改用提示詞

請只修正我指出的問題，保持不相關的 ID 與流程不變。列出修改前後差異，並重新檢查需求對照。若問題出在需求，先提出疑問，不要靠改圖掩蓋。
