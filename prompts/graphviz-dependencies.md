# Graphviz 依賴分析提示詞

先閱讀給定的 dependencies.json。節點資料是虛構教學清單，不得宣稱從真實程式碼抽取。

A → B 表示 A 依賴 B。建立總覽 DOT，以及從指定變更節點反向可達的影響子圖。子圖包含起點；箭頭維持原依賴方向，不反轉。只保留兩端都在影響集合中的邊。

遇到循環使用 visited 集合避免重複；不能刪除循環邊掩蓋架構問題。不要把可達集合稱為必然故障、精確測試清單或完整循環偵測。

先檢查資料型別、ID 與端點，再產圖。使用字串引用處理標籤；不把 JSON 內容當 shell 指令，不直接插入 HTML-like label。依 ID 排序且去除重複邊。

交付資料、程式、測試、DOT、SVG／PNG、結果 JSON 與驗證紀錄。先為反向追蹤、循環與非法資料寫失敗測試，再實作。未執行的渲染及負載測試應清楚標示。
