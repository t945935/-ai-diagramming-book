# 初次使用

## 不使用 Git

在儲存庫首頁按「Code → Download ZIP」，解壓縮後開啟 README.md。目前 ZIP 包含讀者服務文件、Mermaid 樣章、訂單範例、D2 架構樣章、PlantUML 付款三圖及 draw.io 可編輯架構試作，仍不是正式隨書版本。

正式隨書版本發布後，優先從 Releases 下載對應書籍版本，不要假設 main 與紙本完全一致。

## 使用 Git

```sh
git clone https://github.com/t945935/-ai-diagramming-book.git
cd ./-ai-diagramming-book
```

目錄名稱以連字號開頭，請保留 `./`，避免命令將名稱誤認成選項。

## 開啟範例之前

未來每個範例會提供專屬 README，列出工具版本、安裝方法、執行指令、預覽圖與驗證狀態。不需要同時安裝六套工具；依閱讀章節選擇。

Mermaid 並不是所有 Markdown 檢視器都能直接顯示，其他工具的原始檔也不一定能在 GitHub 頁面直接預覽。原始檔、匯出圖與操作說明會分別提供。

遇到問題請參考 [支援說明](../SUPPORT.md)。
