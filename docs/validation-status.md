# 驗證狀態導讀

讀者應同時看目前測試入口和每份歷史實測紀錄。章內「本次」「首次製作」指該章記錄的那一輪，不能把較晚新增的 CI 回填成當時已做，也不能把當時未做 CI 誤讀成現在完全沒有 CI。

## 目前自動檢查

| 檢查 | 方法數 | 實際範圍 |
| --- | ---: | --- |
| Graphviz 生成器 | 3 | 反向可達、循環終止、非法輸入及圖例 |
| D2／draw.io 契約 | 1 | 指定四條呼叫端點及存在性，不比樣式、標籤或容器 |
| 退款規格情境 | 2 | 六個額度與四個結果快照；不是退款 API |
| 除錯實驗室 | 4 | Mermaid／DOT 反例與修正版、反向資料和拼錯端點 |

`make check-core` 執行前三組，合計六個；GitHub Actions 也只執行這六個。`make check-full` 執行全部十個，需要本機渲染器。測試數量指 unittest 方法，不是情境數、斷言數或圖的張數。

CI 以 [workflow](../.github/workflows/core-contracts.yml) 和 [Makefile](../Makefile) 為準，查對應 commit 的 [Actions](https://github.com/t945935/-ai-diagramming-book/actions)。本頁不是永遠有效的綠燈，也不宣稱已設定 required status checks。

## 人工及工具驗證仍分開

| 工具／案例 | 已有歷史證據 | 沒有因此完成的項目 |
| --- | --- | --- |
| Mermaid | 原圖及除錯／退款圖的本機輸出與視覺檢查 | 所有 Markdown 平台、紙本尺寸、原圖 CI 重繪 |
| D2 | dagre 語法／格式與本機 SVG／PNG | 其他引擎、渲染 CI、跨平台 |
| PlantUML | 本機三張付款圖及退款狀態圖 | 真實金流、渲染 CI、跨平台 |
| Graphviz | 資料生成、總覽／子圖及本機視覺檢查 | 大型效能、所有引擎、CI 完整預覽重繪 |
| draw.io | 滑鼠拖曳、API 改字、模型序列化重載 | 原生另存對話框、桌面版、多頁合併 |
| Excalidraw | 匯入、拖曳、瀏覽器重載、真實匯出器 Blob | 原生另存對話框、修改檔案往返、多人協作 |

詳細證據從 [範例入口](../examples/README.md) 進入各自 verification.md。測試資料、SVG XML 檢查、人工視覺走查及 GUI 操作各自只能證明自己的範圍。

## 編輯時保留什麼

保留第 10、11、12 章與原紀錄的歷史測試數量；修正文句中的「目前」與範圍，另附現況導讀。圖檔雜湊、版本、退出碼及未測事項不為了整齊而改寫。既有工作包也是固定快照，不會隨 main 自動更新。
